- **生活身份 = 「南风」**——只有微信个人号用这个名，不对外做公域获客

**个人号的两个建议（不动昵称）**：头像仍用同一套 IP 头像（不是生活照），个性签名写「AI 实战派 · 只讲真做过的用法」——昵称保持生活感，视觉标识不丢，从公域加来的新人第一眼能对上号。

1. **名称唯一性**：公众号名称全平台唯一，先在注册/改名页查「南风AI」是否被占（`AI` 后缀很常见，撞名概率不低）；被占就按备选序：`南风AI笔记` → `南风AI实战` → `南风AI实记`
2. **改名次数**：公众号、视频号的名字变更都有限次（以后台提示为准），一次性改成位，不要反复试
3. **认证主体**：视频号/公众号若已做过认证，名称可能与营业执照/主体资料绑定，改名要确认主体一致性；尤其「南风创意广告」如果当初是按广告类业务认证的，改名后可能需重新验证
