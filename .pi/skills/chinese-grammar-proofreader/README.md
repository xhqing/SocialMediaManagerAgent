# chinese-grammar-proofreader

一个只查中文病句的 Skill。

灵感来自于改了半天突然回忆起来是高中语病题，人工越改越发现很难改，但是然后越改越觉得熟悉，and 就这样了。

**可以极大地提升可读性。** 能不能降低 AI 率不清楚。

## 例子

下面这些句子第一眼都看不出毛病，更多例子在 `references/casebook.md`。

1. 减少实验时间和误差

   "减少时间"搭不上，改成：缩短实验时间并减小实验误差。"提高设备稳定性和使用范围"也是一样，使用范围只能扩大。

2. 通过连续三天的复测，使我们排除了仪器故障

   没有主语，去掉"使"。但"学校通过延长开放时间，使更多学生能够进入实验室"是对的，主语是学校。所以遇到"通过……使……"，这个 Skill 只会复查，不会直接判错。

3. 这项方案经过专家反复论证，项目组最终决定采用第二版

   主语从"方案"换成了"项目组"。改成：经过专家反复论证，项目组最终决定采用这项方案的第二版。

4. 小周告诉小吴，他的申请已经通过了

   "他"指谁，两种读法都通。原意没法猜，所以 Skill 会给出两种改法，让你挑。

5. 是否按时复习，是取得好成绩的重要条件

   前面"是否"有两面，后面只有一面，改成"是能否取得好成绩的重要条件"。

6. 他今天没有发言，因此他一定不同意这个方案

   没发言推不出不同意。

7. 我们发现并排查了故障原因

   顺序反了，先排查才能发现。

8. 改用新方案后，单次计算反而慢了两分钟

   没说跟谁比，改成"反而比原方案慢了两分钟"。

## 逐句检查

之前用的时候，模型经常读一遍就挑几句别扭的改掉，剩下的当没问题，漏的多半就是上面这种读着很顺的句子。现在规定一段话要先切成句子，标题、图注、表格和图里的字也算，然后每句都过一遍；跨句的指代、换主语，还有"均""全部"跟表格对不对得上，也会单独看。长文按节分批查，改过的句子会连同前后句再查一遍。

输出只列有问题的句子，最后写一共查了多少句。要看每句的结论，在提示里说一声就行。

## 查哪些

语序不当、搭配不当、成分残缺或赘余、结构混乱、表意不明、不合逻辑六大类。句式杂糅、指代不明、歧义、关联词错误、两面对一面、否定失当、数量与范围、标点这几项会再单独查一遍。

## 不做什么

不按个人喜好改句子，也不为了显得严格硬挑错。文学性的重复、正常的省略和口语，不按考试作文的标准判。

"通过……使……""由于……因此……""是否/能否"这类结构，先抽主干再判断，不是见到就报错。

## 用法

```
检查这句话有没有语病
按高考语文标准检查下面这段
只找病句，不要润色
找出所有病句，标类型并做最小修改
仔细检查两面对一面、否定和关联词
连标点一起检查
逐句检查这篇稿子，列出每句的结论
```
